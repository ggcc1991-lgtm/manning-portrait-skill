风格分两条线：
- A = 曼宁个人抖音街拍（2024–26年，"MANNING PHOTO"水印）
- B = 柒城"城市旅行"杂志感婚纱照

## 1. 焦段和镜头感
- A：35mm 为主，会贴近拍；也常用 50mm。半身照用 85mm。光圈 f/2–f/4，背景还能认出城市环境。常见 1/15–1/30s 慢门加闪光，人物清晰，背景和裙摆有运动拖影。
- B：24–35mm 拍环境人像（人物和街道、楼群一起入画），50–85mm 拍半身。人物边缘会有轻微广角畸变，显得腿长。

## 2. 角度
- 低机位：相机在腰部到膝盖之间，微微仰拍，拉长腿部，天空或楼群做背景。
- 平视近拍：适合抓拍、笑场和对视。
- 偶尔用荷兰角（倾斜10–15°）和俯拍坐姿。

## 3. 构图
- 主体居中或三分法放置；竖幅 3:4 / 9:16 / 2:3。
- 人物占画面比例大，半身照会紧裁到头顶。
- 街道线条、斑马线、墙面色块做引导线或纯色背景。
- 留出上方空间放杂志标题（AnOther、VOGUE、TOI 等风格排版）。前景常有花束、婚纱裙摆做遮挡。

## 4. 光线
- A（标志性）：机顶直闪或离机硬闪打正面，环境光欠曝 1–2 档。效果是皮肤高光明亮、下巴下面和背后有硬阴影、背景偏暗。夜景常用慢门拖影。白天会用日光闪光补光。
- B：自然光为主。阴天或傍晚的柔光，逆光会有发丝轮廓光；天台黄昏蓝调时刻配蜡烛或烟花等实用光源；棚拍用大柔光箱打纯色背景（灰、粉）。

## 5. 调色（Lightroom 估算值）
### 黑白（A 系列）
曝光 +0.1 / 对比度 +35 / 高光 -30 / 阴影 -15 / 白色 +25 / 黑色 -35；清晰度 +15，纹理 +10；黑白混合：红 +10、橙 +15（提亮肤色）、黄 +5、蓝 -20；
曲线：S 型，暗部压实但不死黑（输出 0→8）；颗粒 25 / 大小 25 / 粗糙度 50；暗角 -12。整体是高反差、带颗粒的纪实胶片感。

### 彩色1：闪光街拍（A）
色温 -200K（偏冷），色调 +5；对比 +25，高光 -25，阴影 -10，黑色 -20；鲜艳度 +10，饱和度 -5。
HSL：红色饱和 +15、明度 -5（红裙要浓）；橙色饱和 -10、明度 +10（皮肤干净）；蓝色色相 -10、饱和 -15；绿色饱和 -30。
色彩分级：阴影 青蓝（210°, 10），高光 暖色（45°, 8）。颗粒 15。

### 彩色2：城市旅行杂志感（B）
曝光 +0.2；对比 +10；高光 -40；阴影 +20；白色 +10；黑色 +10（暗部抬起，有胶片灰）。
曲线：左下点从 0→18，形成哑光感。鲜艳度 +15，饱和 -5。
HSL：橙色明度 +12；红色和粉色饱和 +10；蓝色色相 -15 偏青，明度 -10；绿色色相 +20，饱和 -25。
色彩分级：阴影 青（200°, 8），高光 奶油（40°, 6）。去朦胧 +5。

### 彩色3：棚拍纯色背景（B）
曝光 +0.3；对比 -5；阴影 +15；鲜艳度 +5；整体干净通透，背景颜色统一，几乎不做分离色调。

## 6. 姿势与场景
- 姿势：自然的互动瞬间，比如笑场、对视、拉手奔跑、旋转（裙摆用慢门拖出动感）。拍"街溜子"式松弛感：插兜、墨镜、叼东西、吐舌头、比剪刀手。情侣常亲密贴脸、额头相抵，新娘也会举花或水果。很少用传统僵硬的摆拍。
- 服装：婚纱配西装（白西装、红西装、条纹西装）、高定纱裙（黄、粉、红）、黑色紧身上衣、皮包等时尚单品。
- 场景：深圳和香港的街道、斑马线、老城区骑楼、城市天台和夜景、海边栈道、茶餐厅或酒吧、会议室等"反常规"婚礼场景、纯色影棚。
